# OvenSheen

Enables users to automate monitoring and alerting for their AWS EC2 instances with custom threshold settings.

The key benefits of using OvenSheen include:

- Enables users to automate monitoring
- and alerting for their AWS
- EC2 instances with custom threshold

## Key Features

- Enables users to automate monitoring
- and alerting for their AWS
- EC2 instances with custom threshold

## Technology Stack

- javascript
- javascript framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/OvenSheen.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
